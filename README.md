### **Trustify - Escrow Service for E-commerce**  

**Trustify** is a secure **escrow payment platform** designed to **protect buyers and sellers** in e-commerce transactions. This is a **frontend demo** showcasing the system's workflow.  

---

## **🚀 Tech Stack**
- **Frontend:** React.js, Tailwind CSS  
- **State Management:** useState, useEffect  
- **UI Components:** Tailwind for styling  

---

## **📌 Features (Demo)**
✅ User authentication (login/register UI)  
✅ Secure escrow transaction flow UI  
✅ Order status tracking (funds held, released)  
✅ Responsive design with Tailwind  

---

## **🔧 Installation**
1️⃣ **Clone the repo**  
```bash
git clone https://github.com/fiketekiflu/trustify-Escrow Service for E-commerce.git
cd trustify-frontend
```
2️⃣ **Install dependencies**  
```bash
npm install
```
3️⃣ **Run the app**  
```bash
npm start
```
The app will run at **`http://localhost:3000`**
